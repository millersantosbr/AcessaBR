# Roadmap público

O roadmap expressa direção, não promessa de prazo. Issues específicas são a
fonte de verdade para o trabalho em andamento.

## v0.1 — Alagoas

- [x] painel público responsivo;
- [x] seis portais na primeira coleta;
- [x] dados abertos em JSON;
- [x] metodologia e limitações públicas;
- [x] automação semanal;
- [x] formulários de contribuição;
- [x] publicar as primeiras tarefas `good first issue`;
- [ ] convidar revisores com experiência vivida em acessibilidade.

## v0.2 — Comunidade

- [ ] registrar validações manuais separadas da automação;
- [x] histórico visual das rodadas;
- [x] ampliar o recorte para dez portais;
- [x] exportação CSV;
- [x] esquema JSON versionado;
- [ ] páginas de território;
- [ ] tradução inicial para inglês e espanhol;
- [ ] guia para grupos locais criarem uma coleta;
- [ ] painel de correções informadas;
- [ ] testes com tecnologias assistivas.

## v0.3 — Ferramentas

- [ ] CLI documentada;
- [ ] GitHub Action reutilizável por outros projetos;
- [ ] API somente leitura;
- [ ] catálogo aberto de explicações.

## v1.0 — Brasil

- [ ] múltiplos estados e mantenedores;
- [ ] conselho comunitário;
- [ ] política de moderação escalável;
- [ ] metodologia revisada externamente;
- [ ] processos de correção com instituições;
- [ ] pacote para replicação internacional.
